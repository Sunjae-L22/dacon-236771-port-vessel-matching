# ByT5 후보 조건부 점수 파일럿 준비 기준

상태: 분할 manifest 준비 완료(2026-10-27 16:02). Colab 노트북/학습 코드/가중치/GPU 성능 결과는 아직 없음.

## 고정한 분할 v1

`prepare_split.py` 실행 결과를 `split_v1/rows.csv`, `vessels.csv`, `manifest.json`에 저장했다. 공식 train 12,222행에 기존 `cv.folds(seed=42)`를 적용하고 v1/v2 예시 합집합 108척을 학습으로 강제 이동했다. 조정·평가 쪽에서 이동한 선박은 41척이다.

| 역할 | 전체 행 | 전체 선박 | 한글 행 | 한글 선박 |
|---|---:|---:|---:|---:|
| train (fold 2/3/4 + 예시 선박) | 7,452 | 3,550 | 834 | 269 |
| tune (fold 1 - 예시 선박) | 2,446 | 1,155 | 190 | 61 |
| eval (fold 0 - 예시 선박) | 2,324 | 1,146 | 167 | 52 |

세 역할의 선박 교집합 0과 tune/eval의 예시 선박 0을 assert했다. 표의 전체 행은 두 언어를 포함한다. 신경망의 실제 한글 학습 쌍은 train의 834행을 바탕으로 하며, 중복·가중 처리 전 숫자다. 평가 한글 독립 선박은 52척이므로 작은 파일럿이다.

일반 fold0 OOF 기준 랭커는 fold1을 학습하므로 위 분할의 기준선으로 그대로 쓰지 않는다. 기준 랭커도 `role=train`만으로 학습하고 동일 모델로 tune/eval 후보 점수를 각각 만들어야 한다. LLM 선별 점수 재계산과 후보/모델 생성은 아직 수행하지 않았다.

## 목적

기존 영문 후보가 관측 한글명을 설명하는 조건부 점수가 새로운 보완 신호인지 확인한다. 기존 모델 전체를 교체하거나 시험 점수 향상을 전제로 시작하지 않는다.

## 첫 파일럿의 분할

- 기존 `cv.folds(seed=42)`의 선박 ID 분할을 기본으로 사용.
- 예시: fold 2·3·4는 신경망과 기준 랭커 학습, fold 1은 결합 기준 조정, fold 0은 최종 평가.
- LLM 프롬프트 예시로 사용된 선박은 모두 학습으로 이동시키고 조정/평가에서 제외. 제외·이동 ID와 범위 축소를 manifest에 기록.
- 학습·조정·평가 선박 교집합 0을 assert.
- LLM 행은 학습 선박에 한정. 표기 선별 점수도 학습 부분만으로 계산. real/LLM 출처를 끝까지 보존.
- 기준 랭커와 신경망 모두 최종 평가 선박의 정답/쌍을 학습하지 않음. 전체 train으로 만든 33/36 모델은 독립 기준선으로 쓰지 않음.
- 이 단계는 3-way holdout이며 5-fold OOF로 보고하지 않음.

## 모델과 데이터

- 공개 범용 `google/byt5-small` 후보. 모델 revision, tokenizer/config, 라이브러리 버전을 고정·기록.
- 학습 방향: 영문→한글. 실제 train 한글 쌍을 기본으로, v1 생성 쌍은 보조로 사용.
- 선박별 반복 기록/표기의 총 기여를 기록하고 합성 데이터 수만 늘어 가중이 커지지 않게 제어.
- 신경망 출력 언어·훈련 접두어·이름 정규화·최대 바이트 길이를 미리 고정. 길이 초과가 있으면 잘린 행 수와 비율을 기록.
- 후보가 원래부터 정답을 포함하지 않는 오류와 후보 내 순위 오류를 분리.

## 점수 및 결합

- 우선 상위 20개 후보에 관측 한글명의 teacher-forced log likelihood 계산.
- 같은 행의 모든 후보에 같은 관측 문자열을 점수화하고 pad 토큰은 손실에서 제외.
- 신경망 점수의 순위와 기존 랭커의 순위를 독립 비교한 뒤, 결합 방식·가중은 조정 선박에서만 결정.
- 최종 평가 결과를 보고 가중을 다시 바꾸면 그 결과는 튜닝 결과로 격하하고 새 평가를 확보.
- 원본, 오타1·2, 자모, 절단, 단어 삭제별 결과. 변형은 기존 고정 생성기를 사용하고 동일 행을 모든 모델에 적용.
- 표본 수는 행 수와 독립 선박 수를 모두 표시. 부트스트랩은 선박 단위로 수행.

## L4 속도 측정

- 실제 train 기반 이름 쌍 최소 1,000개. 문자열 길이 구간과 가장 긴 구간을 포함.
- 모델 로드, warm-up, 순수 쌍 점수화, 후보 검색, 전체 저장까지 구분해 측정.
- 한글 1,500행을 확정 사실로 두지 않음. 3,000행×20후보=60,000쌍 상한도 예산에 포함.
- 신경망에 1,200초를 배정하면 30,000쌍은 25쌍/초, 60,000쌍은 50쌍/초가 필요. 실제 속도는 미측정.
- GPU 메모리 최대값, batch size, dtype, 입력/출력 최대 길이, 총 wall time을 결과에 저장.
