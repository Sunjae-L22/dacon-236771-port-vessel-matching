# T001 해석 정정 (2026-10-27)

T001 코드는 KO_DICT=0을 명시했고 그 조건에서의 수치는 유효하다. 그러나 실제 33/36 배포 ZIP 기본값은 1이고 40/41/42만 0이다. 따라서 T001은 33/36의 설정을 그대로 재현한 진단이 아니며, 33→42 차이를 v2만의 효과로 해석할 수 없다. v2 기각을 보류한다.

학습 행 구성 변화 집계는 유지된다. 사전 변화와 순위 수치는 KO_DICT=0에 한정한다. KO_DICT=1의 실제 배포 사전 및 선택 사례 재점검은 `terra/002_20261027-1431_ko-dict-correction-and-byt5-env.md`와 `terra/experiments/20261027_ko_dict_recheck/`를 참조한다. 기존 기록은 보존한다.

범용 사전=1에서도 일부 학습 매핑 왜곡이 남지만, 씨 울프 원본의 GT 창 순위는 회복됐고 에스에이치→cl은 일부 holdout fold에서만 재현됐다. 전체 배포 사전은 에스에이치→sh를 유지했다. 선택한 3척·6개 표기는 전체 성능 추정 표본이 아니다.
