# LLM v1/v2 사전·학습 구성 진단

작성: Terra / 2026-10-27 KST

## 결론

v2 추가는 표기 개수뿐 아니라 학습 언어 비중과 선박별 합성 표기 수를 크게 바꿨다. 독립 선박의 이름 순위는 v2가 원본·오타에서 일부 손해, 절단에서는 일부 이득이었다. 사전 변화의 영향이 존재하지만, 42번 Public 하락의 주원인이나 크기를 이 실험으로 확정할 수 없다. 사전과 랭커 행을 분리한 2×2 재학습 대조가 다음 작업이다.

## 실행 범위

- 공개 train 526행, 독립 선박 167척. 기존 seed42 fold 0·1·2.
- 모든 프롬프트 예시 108척은 학습에만 두고 검증에서 제외. 원래 cv.fold 자체를 바꾸지 않고 해당 예시 선박만 검증에서 제외해 학습에 복귀시켰다.
- 증강 선별 점수는 학습분의 실제 한영 쌍만으로 재계산. 선택된 증강 선박과 검증 선박의 교집합 0을 확인.
- 카탈로그 GT와 입력 GT/IGT ±12% 합집합 내의 KoMatcher 이름 점수 순위만 평가. 현재 제출 랭커, 전체 후보 검색, call_sign override, train 배 사후 제외는 평가하지 않음.
- KO_DICT=0 명시. 변형은 동결된 기존 stress2/stress4 함수 사용, sample_id로 난수 고정. 각 방식에 완전히 같은 변형을 평가.
- 총 9,468회 비교지만 독립 표본은 167척이다.
- 실제 숨은 test 분포를 재현한다는 가정 없음. GPU 학습·서버 시간·Public 결과가 아님.

## 추가 표기의 실제 이름 유사도 (대리지표)

- 프롬프트 예시를 뺀 뒤 v1/v2 표기가 모두 있는 230척을 짝지어 비교.
- 채택된 표기의 실제 train 한글명과 평균 문자열 유사도: v1 0.7409, v2 0.6890.
- 선박별 최고 유사도의 평균: v1 0.7868, v2 0.7952.
- 여러 표기 중 일부는 유용한 다양성이고 일부는 잡음일 수 있다. train 표기 자체도 손상될 수 있으므로 낮은 유사도를 오생성으로 간주하지 않는다.
- 필터 점수는 기존 KoMatcher와의 적합도라 독립적인 표기 품질 점수가 아니다.

## 전체 학습 사전 변화

- v1→v1+v2 새 키 16,351개, 기존 키의 영문 대응 변경 120개.
- 실제 쌍만으로 만든 사전에 있던 키 중, v1과 달리 v2가 다른 대응을 선택한 키는 4개.
- 예: 글로리아 gloria→glory, 디스커버리 discovery→discoverer, 세나 senna→sena, 에스티 sti→sc. 이 중 어떤 대응이 유효한지는 맥락에 따라 달라질 수 있다.
- 기존 사전 키가 그대로라도 새 서브워드가 greedy 분절에 개입할 수 있어 키 덮어쓰기 수만으로 영향 크기를 판단하지 않는다.
- 개별 변화 및 오답 전환은 `dictionary_changes.csv`, `paired_changed_predictions.csv` 참조.

## 다음 대조

### 사전 실패 경로의 구체적 사례

- v2 p2_greedy의 `CL Maoming → 에스에이치 마오밍`(0.7907), `FS Bitumen No.2 → 에스에이치 비트루멘2`(0.8703), `WM Crystal → 에스에이치 크리스탈`(0.7134)이 모두 전체 이름 점수 필터를 통과한다. 알파벳 접두사 자체의 오변환은 전체 점수 필터로 차단되지 않았다.
- fold2의 v2 사전은 `에스에이치`를 `cl`로 고정해 v1의 `SH` 해석을 덮는다. `_translate_single_token`에서 학습 사전이 알파벳 파서보다 앞서 적용되는 경로다.
- fold1에서는 `씨 산 ↔ Ci Yun Shan` 축약 사례가 `씨→ciyun` 대응을 만들 수 있으며, 실제 검증 `씨 울프`의 투영이 `ssiulp→ciyunulp`로 바뀌고 정답 순위가 1→2로 하락했다.
- 같은 토큰 수 경로는 1음절 한글 키를 제외하지만 2:3 정렬 경로는 허용한다. 이 경로에도 음성 유사도 조건은 있으므로 단순 검사 누락으로 설명하지 않는다.
- 근거 원자료: `dictionary_trace_examples.csv`, `paired_changed_predictions.csv`. 개별 오류의 전파를 확인한 것이며 42번 전체 하락의 기여율은 미측정이다.

- A(33): 사전 v1 / 학습 v1. D(42): 사전 v1+v2 / 학습 v1+v2.
- B: 사전 v1 / 학습 v1+v2. C: 사전 v1+v2 / 학습 v1.
- B/C는 해당 사전으로 후보·피처를 만들고 일관된 사전으로 추론하도록 재학습. 기존 모델의 통계 파일만 갈아끼우는 대조는 피한다.
- E: v1의 선박별 개수와 전체 7,967행을 고정하고 v1+v2에서 표기만 재선택해 노출량과 다양성을 분리.
- 자세한 조건은 `ablation_design.json`, 전략·질문 답변은 `../../001_20261027-1412_strategy-and-llm-audit.md`.
