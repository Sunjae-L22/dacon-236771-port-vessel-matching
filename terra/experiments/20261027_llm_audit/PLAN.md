# Terra LLM 증강 진단 계획 (2026-10-27)

- 기준: 36 Public 0.9403, 동일 시드 대조 33(v1) 0.9397 vs 42(v1+v2) 0.9336.
- 목적: v2 추가에 따른 데이터 비중, 선박별 중복, 사전 변경을 측정하고 독립 선박의 이름 점수 영향을 확인.
- 수행: 원본/공유 모델 변경 없이 terra/에 진단 코드와 결과 저장.
- 검증 경계: 공식 test/Private 미접근. 아래는 공개 train의 로컬 진단이며 Public 개선 추정치가 아님.
- 선박 분리: 기존 cv.folds seed42를 사용하되, LLM 생성 예시의 선박은 검증에서 제외하고 학습에 둔다. 생성 표기의 기존 전체-train 점수 대신 학습분만으로 재점수화한다.
- 측정: 실제 증강행 수와 한글 비중, 선박별 기여, 소스별 실제 이름 유사도(품질의 대리지표), 사전 변경, GT±12% 창에서 한글 이름 순위.
- 후속: 사전만/랭커만 증강하는 2x2 대조와 선박별 가중 보정은 본 진단 후 별도로 판단.
