## 변경과분리평가

기존신경망은110상위100후보만채점했습니다. 실제손상오답중51/30행은110의전체후보에정답이없었습니다. 이번에는모델이공식카탈로그의영어이름만출력할수있도록byte prefix trie로검색을제약합니다(beam16,길이보상0,샘플링없음). 동명이선ID를모두보존하고기준110의학습선박제외집합을유지합니다.

기존가중치의조건부확률계산도진단합니다. 출력이름길이로평균을내면긴영어완성이과대평가될수있어,출력전체log확률을query에서예측한길이로나눕니다. 길이비율은각fold의fit학습쌍중앙값만사용합니다.계수2는고정하고탐색하지않습니다.

다음네열을분리해서전부보고합니다.결과를보고유리한설정만남기는자동튜닝은없습니다.

1. 기존상위100+길이계산수정(Rseq재현).
2. 새검색후보만추가하고110원래랭커로선택(retrieval-only).
3. 확장후보+수정한신경망점수.
4. 3번의새선택이전역beam에있고110원래선택은그beam밖일때만교체.모호하면110보존.

110의원래gap>=4행은전부그대로입니다.각hard행의원래top100/점수를먼저복원검증하고새후보를넣습니다.후보가바뀌면상대피처도정상재계산합니다.정답은후보추가나추론조건에사용하지않으며,마지막평가에만사용합니다.

## 해석

Rseq로기존반환점수를재계산한결과clean훼손0/0,noise순증+34/+11입니다.이것만으로0.97을예상할수없습니다.같은개발fold에서실패를본뒤고친방법이므로새로운독립확증으로부르지않습니다.이번카탈로그검색도결과검토전에는제출후보가아닙니다.

0.97에는110의493보다한글21개많은514가필요합니다(E3506고정).검증순증을그대로Public행수로옮겨계산하지않습니다.깨끗한이름훼손0조건을유지하고제출횟수는사용하지않습니다.
