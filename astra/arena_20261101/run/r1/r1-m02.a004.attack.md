ATTACK 1 [MINOR] 동명이선 보존을 총톤수 중복 검사로 대신했다
Where: “동명이선·동일 총톤수 충돌은 전역 유일성 조건으로 보수적으로 제외합니다.” 및 `scratch/a001/probe.py`의 `mechanics_controls['homonym_gt_abstains']`.
Problem: `choose()`는 카탈로그 선박 이름을 받지도 않으며, 해당 검사는 이름이 같은 두 선박이 아니라 GT=100인 ID가 두 개인 경우만 검사한다. 동명이선과 동일 톤수는 다른 조건이다. 정확한 합성 반례는 카탈로그 A=(이름 SAME, GT=200), B=(이름 SAME, GT=100), 입력 `{'vessel_name':'세임','gross_tonnage':100,'international_gross_tonnage':100}`, base=A, gap=1, top5=[A,B]다. `choose(row,'A',1,['A','B'],{'A':200.,'B':100.},{100.:['B'],200.:['A']})`는 B로 교체하므로 동명이선을 제외하지 않는다. 입력 톤수가 틀린 경우 정답 A를 훼손할 수 있다. 이는 실제 평가에서 그런 훼손이 발생했다는 주장이 아니라, 요구사항 “Assess ... robustness to ... homonyms”에 대해 제출한 검사가 보장하는 범위를 잘못 서술했다는 문제다. 공식 카탈로그 실제 동명이선 대상의 적용 여부를 별도로 집계하거나, 검증한 것은 ‘중복 톤수 abstain’뿐이라고 제한해야 한다. 규칙 기각과 변경 0건이라는 측정 자체를 반박하지는 않는다.
