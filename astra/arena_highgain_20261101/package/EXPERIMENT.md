# 고정 실험: 기존 두 신경망으로 미평가 후보 재판별

Arena 3개 제안, 2라운드 공격·수정·독립 심사에서 선택한 `frozen_dual_view_rescue_v1`입니다. 심사 점수는 실험 설계·코드 품질 평가이며 정확도가 아닙니다. **현재 HOLD, GPU 성능 미측정**입니다.

## 무엇을 다르게 보는가

C_vote의 v20은 이미 넓게 검색하지만, 기존 확률 상위20개만 신경망으로 평가합니다. 1·2위 확률차가 크면 신경망을 생략하고, 평가해도 기존 확률75%+신경망25%로 섞습니다. 이번 실험은 이 과정에서 제대로 평가되지 못한 후보를 기존 인코더와 Qwen으로 직접 다시 비교합니다. 새 가중치·새 한글표·새 후보 검색기를 만들지 않습니다.

- 대상: 한글, **원래110 gap<4**, **112와 HanSunwook의 답이 서로 다른 행**. 나머지는 그대로 둡니다.
- 기존 v20 후보 안에서 원래 답 + 기초확률 상위32 + 네 검색 유사도(`sim_key`, `sim_llm`, `sim_compact`, `sim_key_word`)별 양수 상위16을 합칩니다. train 선박 제외, 중복 제거 후 **최대97개**입니다.
- 기존 발음 인코더로 97개를 채점합니다. 인코더 상위8 + 기초확률 상위20 + 원래 답을 기존 Qwen evidence 모델로 채점합니다. **최대29개**, 실제 배치8입니다.
- 두 모델의 1위가 같고 **각 모델 내부** 1·2위 raw logit 차이가 모두1.0 이상일 때만 v20 표를 바꿉니다. 이 값은 사전 고정 조건이며 보정된 정답 확률이 아닙니다.
- 원래112·HanSunwook 표와 바뀐 v20 표를 **원래 C_vote 투표 규칙**에 넣습니다. 새 tie 규칙이나 네 번째 표는 없습니다.

## 왜 이 방향인가

KoCat 후보50→200은 이미112와 Public가 같았습니다. 단순 후보 폭·가중치 변경은 Opus 영역이기도 하므로 제외했습니다. 과거 v15→v18의 검색 확대 이득은 더 넓은 이름 후보가 유용할 수 있음을 보여 주지만, 현재 C_vote의 이득을 증명하지는 않습니다.

다른 큰 방향으로 음절 오류채널/자모 기반 독립 검색, expert 보정·혼합 재학습을 비교했습니다. 독립 검색은 정답 후보 부재가 주원인일 때 유효하므로 이번 실제 trace에서 그 비중을 먼저 확인합니다. 기존 보정 및 encoder confidence 확장 실험의 손실 사례 때문에 단순 신경망 비중 상향도 제외했습니다. 현재 선택 역시 두 신경망이 함께 틀릴 수 있으며, 합성 이득만으로 채택하지 않습니다.

## 명확한 상한

정답이 기존 v20 후보에 없거나, 이97개 풀에 들지 않거나, 112=HanSunwook이거나, 보호된 gap≥4 행이면 이번 방식은 고칠 수 없습니다. 결과에서 `scope_error_rows → pool_error_rows → shortlist_error_rows`를 따로 봅니다. 이 수는 해당 합성 코호트의 정답을 아는 상태에서 계산한 상한이며 실제 회복 수나 Public 예측이 아닙니다. 같은 선박의6변형을 독립 표본으로 세지 않도록 unique vessel 수도 보고합니다.

Public 현재K507/E3506 기준 0.98 초과에는 순증14, 0.985 초과에는 순증18이 필요합니다. 실제25개 한글 오답의56%/72%를 순회복해야 합니다. 이번 실험이 그 규모를 다룰 수 있는지는 아직 알 수 없습니다.

## 실행·검증 계약

원본ZIP SHA 고정 → 세 패키지 동시 실행 → 관찰용 trace 및 후보 packet 저장 → 원본 역순 부분집합 재실행 → 모든 trace/실제 예측/110gap 대조 → 원래 router 무변경 replay → 기존 두 모델만 별도 GPU pass → hash로 묶인 COMPLETE 결과 검증 → 그 뒤에만 정답 평가.

- 원본 추론 파일은 수정하지 않고 외부 hook만 사용합니다. masked+KoCat 점수 뒤에서 기록하며 원래 `score_records` 반환 배열을 그대로 돌려줍니다.
- 추론 packet에는 정답이 없습니다. 원래 모델이 읽었던 행, 후보, 점수, beam과 두 관찰 기록이 일치해야 진행합니다.
- 원래 학습 선박 제외를 보존합니다. 새 pass에서는 Kanana 생성도 반복하지 않고 기존 beam을 재사용합니다. ByT5는 실행하지 않습니다.
- 추가 pass는600초, 전체 진단은 cold start 포함1,800초 watchdog 및07:00KST 중 빠른 시각에 중단합니다. 단계가 실패해도 경과시간·오류·부분 로그를 반환합니다. ABORT partial은 후보 예측으로 집계하지 않습니다.
- 원본 10행 역순 replay와 추가 scorer 최대8행 역순/부분집합 replay가 있습니다. 정식600행 검증을 대체하지 않습니다.
- 실제3,000행 추론 시간·600행 불일치0, 독립 평가의 깨끗한 이름 손해0은 아직 확인하지 않았습니다. 따라서 제출 가능한 후보 ZIP은 만들지 않습니다.

공통 코호트104/400행은 Arena 결과를 읽기 전에 고정했습니다. 우승 제안의 별도256행 세트를 결과에 따라 골라 섞지 않습니다. 두 코호트 모두 table-seen synthetic이며 여기서는 공통 코호트만 실행합니다.

## 로컬 증거

`LOCAL_QA.json`에 실제CPU 모델 검사와 mock 검사를 구분했습니다. 선택된 adapter 23개 테스트, trace audit13개 테스트 통과. 실제112/HSW는8행 원본·계측 출력 동일, 역순8/단독1행 동일, 110 gap 계측 동일입니다. 실제 v20 제어흐름에 테스트 scorer를 붙인 검사에서 hook 전후 배열·호출 수가 동일했습니다. 합성점수를 사용한 통합 fixture에서65위 후보가 최종 답을 바꾸고 영문은 그대로인 경로도 검증했습니다. **이것들은 실제 GPU 정확도 측정이 아닙니다.**
