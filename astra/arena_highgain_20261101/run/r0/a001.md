**실행할 실험은 기존 두 신경망의 판단이 v20의 상위20·0.25 혼합 상한에 막히는지를 확인하는 ‘고정 신경망 재심’이다. 후보 상태는 HOLD이며, 실제 C_vote GPU 실험용 외부 어댑터와 실행기를 준비했다.** 새 모델·재학습·제출은 필요하지 않다. 목표는 그대로 0.98~0.985이고, 그 달성을 예측할 근거는 아직 없다.

전제: 사용자 제공 C_vote ZIP을 기준으로 삼되 실제 제출물의 해시 동일성까지 확인된 것은 아니다. 전체 모델이 보지 않은 독립 정답 자료와 Public 잔여25개 오류 ID는 없다. GPU는 사용자가 실행한다.

### 왜 이 방향인가

확인한 실제 소스는 `astra/arena_20261101/baseline/model/ko/model/src/encoder_views.py`, `pair_views.py`, `encoder_phonetics.py`, `pair_evidence.py`, `ensemble.py`, `model/ko/script.py`, 최상위 `script.py`다.

### 고정된 실험 정의

1. 범위는 **한글·원래110 gap<4·112와HSW 예측 불일치**다. 영어와 보호행을 유지한다. 112=HSW이면 v20만 바꿔도 최종 다수결은 바뀌지 않으므로 점수화하지 않는다.
2. 질의별 후보를 다음 합집합으로 고정한다: 원래 조정확률 상위20, **KoCat/제외 보정 전 ensemble확률 상위20**, 기존 `sim_key` 상위10, 기존 `sim_llm` 상위10, 실제 세 구성모델의 예측ID. 최대63개다. 모든 목록에서 production 학습제외ID를 먼저 제거한다. 유사도0 후보는 해당 유사도 목록에 넣지 않는다. 동점은 vessel ID 사전순으로 고정한다.
3. 원래 query-only Kanana beams를 그대로 사용한다. 모든 후보를 기존 `ViewScorer(...,"qwen","evidence")`와 `ViewScorer(...,"encoder","phonetic")`로 점수화한다. microbatch4, FP/BF16 설정은 기존 클래스 그대로다. 새로운 음역 생성·KC표·가중치 변경은 없다.
4. 두 view가 동일한1위에 합의하고, **각자의 native logit1·2위 차이가1.0 이상**일 때만 실험용 v20값을 그 ID로 바꾼다. 점수 단위가 다른 두 모델을 평균하지 않는다. 1.0은 사전 고정한 공학적 필터이며, 검증된 확률/신뢰도 기준이 아니다. 불일치·작은 차이는 원본을 유지한다.
5. 새 v20값과 원래112/HSW값을 **원본 C_vote 라우터 그대로** 통과시킨다. OOM/누락/NaN/실패는 실행 중단이다. 실패를 abstention으로 위장하지 않는다.

이 방법이 접근할 수 없는 영역은 명확하다. 영어·보호행, 112=HSW 오답, 63후보 밖 정답, 두 동결 신경망의 공통 오류는 고치지 못한다. 현재25한글오류 중 이 방법으로 접근·회복 가능한 수를 R, 새 훼손을 H라 하면 순이득 상한은 R−H≤25다. 0.98에는R−H≥14, 0.985에는≥18이 필요하다. 즉 잔여오류의56%/72% 순회복이 필요하다. **R이14 미만이면 이 방향 하나로0.98은 불가능하다.** 현재 R은 알 수 없다. 전체 test의 적용행 수를 Public 적용행 수로 바꾸어 말하지 않는다.

### 공통 GPU 실행 묶음에 붙일 정확한 위치

**Capture hook 위치는 중요하다.** `model/ko/script.py::predict_ranker()`에서 `EncoderViewsEnsemble.load(MODEL_DIR,retriever)`가 반환된 직후, 그리고 `masked_score_groups`를 설치하기 **전**에 `install_capture(neural,emit)`를 실행한다. 파일은 고치지 않고 외부 launcher에서 클래스의 `load`를 감싼다.

```python
original_load = EncoderViewsEnsemble.load.__func__
@classmethod
def traced_load(cls, folder, retriever):
    return install_capture(original_load(cls, folder, retriever), emit)
EncoderViewsEnsemble.load = traced_load
```

이 함수는 원래 base호출에서 raw복사본을 받고, `score_records` 실행 시점의 기존 masked호출에서 adjusted복사본을 받는다. 재추론하지 않고 원래 반환배열을 그대로 반환한다. 원본 source hash 검사를 통과한 뒤 객체만 감싼다. 기존 공통 trace hook을 함께 쓸 경우 이 load wrapper를 모델 로드 전에 설치하고, 원래 per-view score trace도 유지한다.

`emit` JSONL의 행별 필드는 `sample_id,row,pool[{id,raw,adjusted,sim_key,sim_llm}],llm_beams,baseline_top20,baseline_neural_skipped,v20_final_scores`다. 공통 trace의 `base_prob`는 **이미조정된 값**이므로 raw로 대입하면 안 된다.
