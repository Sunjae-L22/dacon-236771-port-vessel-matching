# C_vote 이후 다른 방향 검증 결과

**결론: 이번에 검증한 새 방향에서 0.98을 뒷받침하는 후보는 나오지 않았다. 신규 후보는 모두 기각했으며 제출0회다.**

**기준:** C_vote Public 0.9618922587, 한글 507/532·영문 3506/3568. 영문을 그대로 두면 0.98 초과에는 한글 순구출 14개, 0.985 초과에는 18개가 필요하다. 아래 오프라인 행 수를 이 Public 행 수로 환산하지 않는다.

사용자 요청에 따라 이전 확률적 노이즈 채널 방식은 보류했다. 모든 새 파일은 astra/에만 만들었고, Opus의 72B 생성·v20t·F1·융합 파일은 수정하지 않았다. 제출하지 않았으며 신규 후보 ZIP도 만들지 않았다. 07:00 이후 신규 후보 금지를 유지한다.

## 검증한 방향

| 방향 | 직접 실행 결과 | 판단 |
|---|---|---|
| 여러 가능한 음역을 보존하는 토큰 사전/lattice | 실제 한글 1,191행, 선박별 5fold에서 기존 단일 표기 대비 추가 정답 후보 0 | 현재 데이터에서 큰 개선 근거 없음 |
| 학습 선박을 검색 전에 제외해 후보 슬롯 회수 | 실제 이름 330개+오타 990개에서 기존 3검색 채널 합집합 1,309→1,310 | 검색 누락의 주된 해결책 아님 |

재학습 비교의 기존 62피처 모델은 이전 대리모델과 예측 불일치0이었다. 원본110 gap과 학습/평가 선박 분리를 독립 검토했다. 평가 독립 단위는 fold2 69척, fold4 68척이며 수천 변형 행을 독립 표본으로 보면 안 된다. seed1개와 feature_fraction=.8의 한계도 있다.

## 실제 C_vote 원본 가중치 기준 비교 완료

원본 C_vote ZIP의 SHA256은 `601c71ab3bc87ee5128305261c1708c432eb75dca53258e4d3841cce813a97d3`과 일치했다. 원본 소스/가중치를 astra/에 복사하고 런타임 device 기본값만 CUDA→MPS로 바꿔 실행했다. 소스 자체는 원본으로 복원해 내장 source hash 검사를 통과했고, 출력 점수가 모두 유한한지도 검사했다.

로컬 pandas3/Transformers5와 원본 모델의 호환 문제가 있어 astra/ 안에 pandas2.2.3·Transformers4.57.6을 설치했다. 112와 HSW도 pandas2로 다시 실행했으며 이전400행 대비 예측 불일치0, 110 gap 불일치0이었다. 기존 환경 결과는 `local_cvote/eval_pandas3_superseded/`에 따로 남겼다. CUDA와 수치적으로 같은 결과라는 보장이나 L4 시간 측정으로 부르지 않는다.

평가 입력은 고정64척에서 만든 **표를 이미 본 합성 진단400행**이다. 국가·선종은 영어 카탈로그 라벨을 그대로 넣던 기존 오류를 고쳐 공식 train에서 얻은 한국어 대응으로 바꿨다. 대응이 없는 필드는 결측으로 남겼다. 이름 표와 정답 카탈로그에서 만든 메타데이터의 합성 편향이 남으므로 Public 예상점수에는 사용하지 않는다.

| 비교 | C_vote 대비 바뀐 행 | 구출 | 훼손 |
|---|---:|---:|---:|
| E5가112를 바꾼 hard행에서 C_vote 답도 교체 | 3 | 0 | 0 |
| 112를 E5 보정 답으로 바꾼 뒤 원래3자투표 적용 | 0 | 0 | 0 |

고정 E5 점수는 112 답4개를 바꿨고 그중1개가 정답이었다. 그러나 **그1개는 v20 및 C_vote가 이미 맞히고 있었다.** 나머지3개는 오답→다른 오답이었다. 변경 가능성이 있는 모든4행을 원본 v20으로 실행했고, 나머지396행은 원래 C_vote 답을 그대로 반환한다. 전체400행의 C_vote 정확도를 측정한 것으로 해석하지 않는다.

4행 순서를 바꿔 재실행한 결과 예측 불일치0이었다. 이는4행 확인이며600행 독립성 검증을 대신하지 않는다. v20 첫실행40.29초, 순서재실행33.01초는 Mac 로컬 측정이다. 후보를 기각했으므로 3,000행/L4·600행 제출본 검증이나 후보ZIP 제작으로 진행하지 않았다.

원자료: `local_cvote/eval/CVOTE_COMPARISON.json`, `CVOTE_COMPARISON_ROWS.json`; 실행환경·출처는 `local_cvote/RUNTIME_ENVIRONMENT.json`, `RUNTIME_DEVICE_MANIFEST.json`, `PREPARE.json`.

## 이전 예측 정정

이전 CPU 보고의 조건부 Public 0.9643 전망은 철회했다. 그 합성 입력은 국가·선종을 모델이 배운 한국어 대신 영어 라벨로 넣었다. 기존 구출 수는 그 입력에서의 실행 결과일 뿐, 제대로 맞춘 입력이나 Public 상승폭의 근거가 아니다.

## 연구와 적용 범위

[Lost in Transliteration, SIGIR 2025](https://eprints.gla.ac.uk/352746/)은 음역 질의에서 다국어 dense retrieval이 약해지고 추가 학습으로 회복될 수 있음을 다룬다. 선박에서 0.98을 보장하는 논문은 아니다. 이번에는 [공개 multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) 가중치를 재사용해 실제 학습·검색 비교를 수행했다. 외부 선박 데이터는 사용하지 않았다.
