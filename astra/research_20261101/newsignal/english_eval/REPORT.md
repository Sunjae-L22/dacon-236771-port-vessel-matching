# 실제 영문 holdout: 정규화 오류 채널 v2

**결과: 순증 0.** 실제 영문 이름에서는 기본 문자열 검색이 이미 거의 모두 맞혔고, 새 채널과 고정 0.99 조건 모두 예측을 한 행도 바꾸지 않았다. C_vote 평가나 Public 점수 예측이 아니다.

| 평가군 | 행 / 선박 | fuzz.ratio | 채널 | 채널 ≥0.99 | 구출 / 훼손 |
|---|---:|---:|---:|---:|---:|
| 전체 실제 입력 | 1,097 / 1,096 | 1,095 | 1,095 | 1,095 | 0 / 0 |
| 정규화 후 깨끗한 입력 | 680 / 680 | 680 | 680 | 680 | 0 / 0 |
| 실제 비일치 입력 | 417 / 417 | 415 | 415 | 415 | 0 / 0 |

## 사전 고정한 방식

- `english_pairs.jsonl`에서 `sha256('channel-v1:' + vessel_id)[:8] mod 5 == 0`만 평가. 채널 학습 선박과 겹침 0. 실제 관측 형태를 사용했고 새 오류를 합성하지 않았다.
- 공식 카탈로그 78,595척에서 `NORMALIZED_FIT.json`의 학습 선박 4,342척만 제외하여 **74,253척 전체**를 검색했다. holdout 정답은 모두 남아 있다.
- 정규화는 원본 pair 생성 방식과 동일한 NFC + 영숫자만 유지 + 대문자다. '깨끗함'은 이 정규화 후 질의와 카탈로그 이름이 같다는 뜻이며 원시 표기 동일성을 뜻하지 않는다.
- 기준은 `rapidfuzz.fuzz.ratio`의 전체 후보 최고점, 동점은 오름차순 vessel_id. normalized Indel similarity다.
- 채널 후보는 **unrestricted Damerau-Levenshtein ≤2** 전체 결과다. OSA를 쓰지 않는다. 각 후보의 0/1/2회 전이 경로 확률을 모두 합산한다. 양수 확률 후보가 없으면 기준 예측으로 돌아간다.
- 별도 고정 조건은 `최상위 후보 확률 / 모든 양수 후보 확률 합 ≥0.99`. 미달 시 기준으로 돌아간다. 이 비율은 모델 내 상대 질량이지 실측 신뢰도 보정값이 아니다.
- 파라미터·조건 조정 없음. 한국어 결과와 C_vote 예측은 읽지 않았다. 정답은 채점 및 결과의 연산 분류에만 사용했다.

## 오류 종류별

연산 분류는 실제 생성 이력을 안다는 뜻이 아니다. 정답 이름→관측 이름을 설명하는 최소 전이 수의 가능한 연산을 사후 표시한 것이다.

| 가능한 최소 연산 | 행 수 | 기준 정답 | 채널 정답 | 구출 / 훼손 |
|---|---:|---:|---:|---:|
| 삭제 1회 | 122 | 122 | 122 | 0 / 0 |
| 중복 1회 | 136 | 136 | 136 | 0 / 0 |
| 인접 교환 1회 | 126 | 126 | 126 | 0 / 0 |
| 삭제 2회 | 9 | 9 | 9 | 0 / 0 |
| 삭제+중복, 순서 복수 가능 | 12 | 12 | 12 | 0 / 0 |
| 삭제+교환, 순서 복수 가능 | 4 | 4 | 4 | 0 / 0 |
| 채널 밖 | 8 | 6 | 6 | 0 / 0 |

정답 후보가 거리 필터에 포함된 것은 **1,095/1,097**이다. 정답에 양수 채널 확률이 있는 것은 **1,089/1,097**이며, 실제 비일치 입력에서는 **409/417**이다. 채널 밖 8행도 제거하지 않고 평가에 포함했다. 이 8행은 모두 양수 후보가 없어 기준으로 복귀했다.

채널 밖에는 `MV` 접두어 5행, 유니코드 로마 숫자 2행, `BW WREN` 대 `HAFNIA WREN` 1행이 있었다. 최종 오답 2행은 `DREAMⅡ`와 `HAFNIAWREN`이었다. 이 결과를 본 뒤 정규화·별칭 규칙을 추가하지 않았다.

## 시간과 재현 자료

한 CPU 프로세스, 스레드 환경 변수 1에서 전체 **13.84초**: 기준 검색 1.60초, Damerau-Levenshtein 필터 11.57초, 채널·연산 분류 0.34초. 읽기/초기화 등을 포함한 전체 시간이다. **L4 또는 C_vote 전체 실행 시간은 아니다.**

- 실행 코드: `evaluate.py`
- 모든 행 예측: `predictions.jsonl`
- 세부 수치·고정 파라미터·입력 및 코드 SHA-256: `SUMMARY.json`
- 실행 로그: `run.log`

후보가 여러 개일 때의 경쟁도 실제 발생했다: 양수 채널 후보가 2개 이상인 행 93개, 0.99 미달 행 53개. 따라서 후보가 항상 하나라서 조건이 무의미했던 시험은 아니다. 다만 기준과 채널의 최상위 답이 모두 같았으므로 이 자료는 새로운 구출 근거를 제공하지 않는다.

새 채널의 영문 holdout 일반화 동작과 이 범위의 clean 피해 0을 확인했다. **한국어 개선 또는 C_vote 대비 이득의 근거로 전환해 해석하면 안 된다.**
