## 3. 오늘 할 일

### 트랙 A: 학습 없이 바로 낼 것 (오전 중)

1. **58번과 48번:** 내가 이미 제출했고 점수를 기다리는 중이야. 점수가 나오면 알려 줄게.
2. **다른 방법의 모델끼리 투표 앙상블:** `shared/src/make_vote.py`로 36 + 47 + 55를 묶어. 행마다 다수결이고, 셋이 모두 다르면 36을 따라. 세 모델은 각자 0.938~0.940이고 방법이 달라서, 틀리는 행도 서로 다를 가능성이 있어.
   - **주의:** 최근 제출본의 `script.py`는 `PYTHONHASHSEED`가 없으면 `os.execve`로 자기 자신을 다시 실행해. 그런데 make_vote는 멤버를 `python -c` + runpy로 띄워서, 재실행되면 인자가 깨져. 멤버를 띄우는 `subprocess.Popen`에 `env=dict(os.environ, PYTHONHASHSEED="0")`을 꼭 넣어.

   - 58이나 48이 36을 넘으면 투표 멤버를 바꿔서 한 번 더 만들어.

### 트랙 B: 큰 한 방, 추론할 때 LLM으로 후보 다시 매기기 (오늘~10/30)

0.04 차이는 피처를 하나씩 더해서는 안 줄어. 손실은 대부분 손상된 한글 이름에서 나와. 공개 사전학습 가중치는 규칙상 허용되고, 서버에 L4 GPU(22GB), transformers 4.57.6, torch 2.7.1이 있어. 그런데 우리는 GPU를 한 번도 안 썼어.

**아이디어:**
1. 지금 랭커(36 방법)가 한글 행마다 상위 K개 후보(K=10~20)를 뽑아.
2. 공개 LLM(Qwen2.5-3B 또는 7B Instruct)이 각 후보의 영문 이름이 한글 이름의 음차일 가능성을 점수로 매겨. 생성하지 말고, `"한국어 선박명: {ko}\n영문 선박명:"` 뒤에 `" {EN_NAME}"`가 붙을 log-prob를 teacher-forcing으로 계산해(토큰 수로 정규화).
3. 최종 점수 = 랭커 점수 + w × (후보 사이에서 표준화한 LLM 점수). w와 K만 검증 데이터에서 정해. LightGBM은 다시 학습하지 않아.
4. 계산량은 한글 약 1,500행 × 후보 20개 = 3만 개 짧은 시퀀스야. L4에서 3B fp16이면 몇 분이면 될 거야. Colab에서 실제로 재.

**검증 방법:** 이미 있는 것을 재사용해.
- **분할:** `terra/byt5_pilot/split_v1/rows.csv` (train / tune / eval 선박 분리)
- **기준 랭커:** `shared/experiments/byt5_baseline/ranker.txt`. train 역할로만 학습했고, 만든 스크립트는 `shared/src/byt5_baseline_opus.py`야.
- **원본 한글은 이미 1.000이라 개선 여지가 없어.** 그러니 tune/eval 한글 행에 손상 변형을 만들어 써. 오타 1·2, 자모 오류, 절단, 단어 삭제, 순서 바꿈, 개명이고, 생성기는 `shared/src/opus_stress3.py`의 `variants`, `opus_stress4.py`의 `V`, `opus_stress2.py`의 `V`에 있어. 변형마다 상위 20후보와 랭커 점수 CSV를 만들어.
- **Colab 노트북:** 내가 실행할게. 이 CSV에 LLM 점수를 붙여서 드라이브(`내 드라이브/항만_llm_aug/`)에 저장하는 노트북을 만들어 줘. 처리량(초당 쌍 수)도 함께 기록해.
- **로컬:** tune으로 w와 K를 정하고, eval에서 변형별 acc@1을 기준선과 비교해.
- **판정:** eval 손상 변형 전체 평균 acc@1이 **+2%p 이상**이고 원본이 1.000을 유지하면 제출본을 만들어. 그보다 작으면 7B로 한 번만 더 시도하고 접어.

**제출본으로 만들 때:**
- 가중치를 `model/` 아래에 넣고 `local_files_only=True`로 불러.
- ZIP은 10GB 이하여야 해. 3B fp16은 약 6GB라 들어가.
- GPU가 없는 환경에서는 LLM 단계를 건너뛰고 기존 예측을 그대로 내게 해.
- 서버 시간: 모델 로드 + 기존 추론 약 8분 + LLM 점수. 30분 안이어야 해.
- 로컬은 맥이라 CPU 점검만 하고, GPU 경로 점검은 Colab에서 `script.py`를 그대로 돌려 확인해.
