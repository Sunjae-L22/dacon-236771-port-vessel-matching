# v18 + 우리 모델 결합 키트

필요한 것: 이 폴더 전체 + `v18_fuzzy500.zip`(싸피 PC의 `dist/` 안, 약 6.65GB). Python 3.11, pandas·lightgbm·rapidfuzz·catboost·torch·transformers가 설치된 환경(싸피 PC의 대회용 환경 그대로)과 **NVIDIA GPU**(v18의 Kanana 음역이 CUDA 필요).

## 만들 제출본 2개

| 이름 | 한글 행 | 영문 행 | 예상 |
|---|---|---|---|
| **A_combo.zip** | v18 그대로 | 93 | 한글 500 / 영문 3506 = **0.9527** (두 기록에서 바로 계산) |
| **C_vote.zip** | 우리 확신 행은 110, 나머지는 v18·HanSunwook(1031_08)·110 다수결(셋 다 다르면 v18) | 110(=93) | 세 파이프라인 오답 종류가 달라 A 이상 기대. `1031_08_hyb_w.zip`(HanSunwook 제출 ZIP) 필요 |
| **B_fuse.zip** | 우리 모델이 확신하는 행(1·2위 점수차 ≥ 4, Public 실측 정밀도 371/373)은 110, 나머지는 v18 | 110(=93) | 최악 A−2행(0.9500), v18이 우리 확신 행에서 틀린 만큼 상승 |

## 싸피 PC에서 (가장 빠름)

이 폴더에서 명령 창을 열고, `V18`에 실제 경로를 넣습니다.

```
python build_combo.py A_combo.zip V18경로\v18_fuzzy500.zip 93_submit.zip
python build_fuse.py  B_fuse.zip  V18경로\v18_fuzzy500.zip 110_submit.zip
python build_vote.py  C_vote.zip  V18경로\v18_fuzzy500.zip 1031_08_hyb_w.zip 110_submit.zip
python check_combo.py A_combo.zip
python check_combo.py B_fuse.zip
python check_combo.py C_vote.zip
```

- 각 `check_combo.py`는 ZIP을 풀어(약 7GB, 디스크 여유 15GB 필요) 3,000행을 돌리고 마지막에 **OK**가 나와야 합니다. `[2]`와 `[3]`이 0이 아니면 제출하지 마세요.
- 시간이 없으면 check는 A만 돌려도 됩니다(B는 맥에서 같은 코드로 이미 리허설 통과).
- 제출 순서: **A 먼저**, 그다음 C(HanSunwook ZIP이 있을 때), 그다음 B. 가장 높은 쪽을 최종 선택.
